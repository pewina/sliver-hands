# SilverHands Universal Business Advertisement Poster

The Content Creator now turns the skills identified during voice onboarding into a category-aware 4:5 business advertisement.

## Flow

Voice skill identification -> SilverHands profile -> AI marketing copy -> category inference -> adaptive poster -> profile QR -> WhatsApp/Instagram/Facebook content

## Supported poster behavior

- Food / Culinary: warm culinary palette and food iconography
- Tailoring / Fashion: elegant fashion palette and tailoring iconography
- Handicrafts / Art: handcrafted earthy palette
- Tutoring / Education: trustworthy academic palette
- Beauty / Salon: premium beauty palette
- Gardening / Plants: fresh organic palette
- Home Services: professional service palette
- Creative Services: modern creative palette
- Traditional Arts: traditional-modern palette
- Other niches: professional SilverHands fallback style

## Profile-driven content

The screen reads the skills, experience, language, location and display name already stored in `DemoStore`, which is populated by the voice onboarding/profile flow. The user does not need to enter the skills again.

## Photo and QR

- A business/product/profile photo can be selected directly in the poster screen.
- Flutter Web uses image bytes and `Image.memory`, so Chrome does not hit the `Image.file` assertion.
- The QR code is generated by the app with `qr_flutter` and kept inside a white high-contrast container at the bottom of the poster.
- The poster does not ask an image model to redraw the QR code.

## WhatsApp

The WhatsApp copy is still generated separately and the existing Share to WhatsApp button opens WhatsApp/WhatsApp Web with the message pre-filled.
